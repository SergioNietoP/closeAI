About CloseAI

CloseAI is an AI experimentation platform that showcases various applications of artificial intelligence. Built with OpenAI's powerful models, this platform demonstrates practical use cases including:

  • Automated interview evaluation and feedback
  • Intelligent question generation for assessments
  • Advanced text analysis and processing
  • Interactive chat with AI assistance
  • Audio transcription and analysis (Whisper API)

Whether you're exploring AI capabilities, building similar tools, or conducting research, CloseAI provides hands-on examples of what's possible with modern AI technology.

Technology Stack

Backend: Python, Flask
AI: OpenAI GPT-3.5, Whisper
Frontend: HTML5, CSS3, JavaScript
Tools: LangChain, ChromaDB, PineCone
